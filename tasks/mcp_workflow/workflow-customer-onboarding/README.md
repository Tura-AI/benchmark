# workflow-customer-onboarding

Read the CRM record, create and upload the onboarding plan, schedule kickoff, and send the customer welcome email.

Mock services: HubSpot, Google Docs, Google Drive, Google Calendar, Gmail. Official MCP tools use versioned public vendor contracts; products without an official MCP are explicitly marked as vendor API adapters. The server uses MCP JSON-RPC over stdio while keeping all external side effects deterministic and local to one benchmark attempt.
