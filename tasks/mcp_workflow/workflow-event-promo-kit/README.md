# workflow-event-promo-kit

Read a Calendar event, create its Canva card, resize it in Photoshop, and send it to attendees through Gmail.

Mock services: Google Calendar, Canva, Adobe Photoshop, Gmail. Official MCP tools use versioned public vendor contracts; products without an official MCP are explicitly marked as vendor API adapters. The server uses MCP JSON-RPC over stdio while keeping all external side effects deterministic and local to one benchmark attempt.
