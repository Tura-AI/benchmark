# workflow-social-thumbnail-approval

Export a Figma frame, enhance it in Photoshop, and post the final thumbnail to the correct Slack channel.

Mock services: Figma, Adobe Photoshop, Slack. Official MCP tools use versioned public vendor contracts; products without an official MCP are explicitly marked as vendor API adapters. The server uses MCP JSON-RPC over stdio while keeping all external side effects deterministic and local to one benchmark attempt.
