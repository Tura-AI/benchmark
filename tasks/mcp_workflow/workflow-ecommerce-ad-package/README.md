# workflow-ecommerce-ad-package

Combine Drive media in Premiere, export the ad cut, create its Photoshop thumbnail, and post both outputs to Slack.

Mock services: Google Drive, Adobe Premiere Pro, Adobe Photoshop, Slack. Official MCP tools use versioned public vendor contracts; products without an official MCP are explicitly marked as vendor API adapters. The server uses MCP JSON-RPC over stdio while keeping all external side effects deterministic and local to one benchmark attempt.
