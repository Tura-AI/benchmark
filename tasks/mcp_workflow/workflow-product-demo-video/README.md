# workflow-product-demo-video

Find raw footage, build and edit a Premiere sequence, export the review cut, and deliver it with Gmail.

Mock services: Google Drive, Adobe Premiere Pro, Gmail. Official MCP tools use versioned public vendor contracts; products without an official MCP are explicitly marked as vendor API adapters. The server uses MCP JSON-RPC over stdio while keeping all external side effects deterministic and local to one benchmark attempt.
