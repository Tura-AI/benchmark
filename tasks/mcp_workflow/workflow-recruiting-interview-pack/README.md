# workflow-recruiting-interview-pack

Retrieve candidate files, crop the headshot, create an interview brief, schedule the panel, and email the full pack.

Mock services: Google Drive, Adobe Photoshop, Google Docs, Google Calendar, Gmail. Official MCP tools use versioned public vendor contracts; products without an official MCP are explicitly marked as vendor API adapters. The server uses MCP JSON-RPC over stdio while keeping all external side effects deterministic and local to one benchmark attempt.
