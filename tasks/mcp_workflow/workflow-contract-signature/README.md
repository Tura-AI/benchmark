# workflow-contract-signature

Retrieve a contract, add an Acrobat signature field, export it, email the signer, and schedule the reminder event.

Mock services: Google Drive, Adobe Acrobat, Gmail, Google Calendar. Official MCP tools use versioned public vendor contracts; products without an official MCP are explicitly marked as vendor API adapters. The server uses MCP JSON-RPC over stdio while keeping all external side effects deterministic and local to one benchmark attempt.
