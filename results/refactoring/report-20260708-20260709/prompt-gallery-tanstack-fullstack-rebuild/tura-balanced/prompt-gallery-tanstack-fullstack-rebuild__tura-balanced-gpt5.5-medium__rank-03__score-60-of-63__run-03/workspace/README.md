# POWERPROMPT Marketplace

Full-stack TanStack Start rebuild of `makeup.html` with a local file database, server functions, API routes, persistent seed data, checkout simulation, and creator analytics.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run test:db`
- `npm run test:api`
- `npm run test:e2e`

The database is created at `data/powerprompt.db.json` from `src/data/seed.ts` when the app or tests first read it.
