## Purpose and Scope

This document catalogs the TanStack Start example applications for React, Solid, and Vue frameworks. These examples showcase full-stack applications leveraging TanStack Start's features such as server-side rendering (SSR), streaming, server functions, and optional static generation capabilities. Each example explores different patterns of integration with state management libraries, UI frameworks, authentication providers, and diverse deployment strategies including Nitro, Bun, and srvx-based static serving.

For in-depth details about TanStack Start framework architecture, refer to [5.1 Start Architecture](https://github.com/TanStack/router/blob/ecbbd9a8/5.1%20Start%20Architecture) For SSR capabilities, see [5.2 Server-Side Rendering](https://github.com/TanStack/router/blob/ecbbd9a8/5.2%20Server-Side%20Rendering) For server function usage patterns, see [5.3 Server Functions](https://github.com/TanStack/router/blob/ecbbd9a8/5.3%20Server%20Functions)

## React Start Examples Overview

React Start example applications utilize `@tanstack/react-start` as their core for SSR and routing. They typically include `@tanstack/react-router`, type-safe routing integration, React Query for data management (in some), and devtools for development support. Vite is the de-facto build system, and deployments are either Nitro server or static serving via `srvx`. Most examples use Tailwind CSS for styling.

### Common Scripts Pattern

| Script  | Command                                    | Purpose                                    |
| ------- | ------------------------------------------ | ------------------------------------------ |
| dev     | vite dev                                   | Starts development server with HMR         |
| build   | vite build && tsc --noEmit                 | Production build with type check           |
| preview | vite preview                               | Preview production build                   |
| start   | node .output/server/index.mjs or pnpx srvx | Starts production server or static hosting |

This pattern is consistent across most React examples [examples/react/start-basic/package.json6-11](https://github.com/TanStack/router/blob/ecbbd9a8/examples/react/start-basic/package.json#L6-L11)
