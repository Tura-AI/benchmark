Member 📢 This is a breaking change for people using API Routes in TanStack Start.

As part of the conversation here ([#2800](https://github.com/TanStack/router/discussions/2800)) on the need for `apiBase` for API routes, the export for a file containing an API Route shall change as follows.

```
import { createAPIFileRoute } from '@tanstack/start/api'

- export const Route = createAPIFileRoute(...)
+ export const APIRoute = createAPIFileRoute(...)
```

Although we still aren't sure, as to whether we'll be making the change regarding the removal of `apiBase` and allowing API routes to be defined on *any* route, this is a low-impact change that leaves the door open for such changes should we decide to pursue it
