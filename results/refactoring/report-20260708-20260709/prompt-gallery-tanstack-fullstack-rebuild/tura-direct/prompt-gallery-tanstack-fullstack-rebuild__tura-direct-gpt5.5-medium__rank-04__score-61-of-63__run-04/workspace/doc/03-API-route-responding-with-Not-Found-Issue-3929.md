### Describe the bug

Here is my file tree for my api routes:

```
.
├── app/
│   ├── routes/
│   │   ├── `__root.tsx`
|   |   └── `api`
|   |       ├── `auth.apple`
|   |       |  ├── `authorize.ts`
|   |       |  └── `callback.ts`
|   |       └──  `auth.google`
|   |          ├── `authorize.ts`
|   |          └── `callback.ts`
│   ├── `client.tsx`
│   ├── `router.tsx`
│   ├── `routeTree.gen.ts`
│   ├── `ssr.tsx`
|   └── `api.ts`
...
```

The routes /api/auth/google/... work but the routes for /api/auth/apple/... do not
